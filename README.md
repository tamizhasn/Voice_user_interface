# Voice User Interface (VUI) Assistant

This project is a Python-based Voice User Interface (VUI) assistant that enables users to interact with their computer through natural voice commands. It performs tasks such as opening applications, reading news, translating text, telling jokes, sending emails, playing YouTube videos, typing text, and answering questions using Wikipedia. The assistant offers a hands-free and accessible way of interaction, making daily tasks easier and faster.

## Features

- **Speech Recognition & Text-to-Speech**: Understands voice commands and responds audibly.
- **Application Control**: Open apps like Firefox, WhatsApp, and Camera.
- **Information Retrieval**: Search Wikipedia and Google for information.
- **Translation**: Translate English text to Tamil.
- **Media Playback**: Play music or videos via YouTube.
- **Email Sending**: Compose and send emails using voice commands.
- **Voice Typing**: Dictate text to applications like Notepad.
- **Entertainment**: Tells jokes and provides date/time information.
- **Graphical User Interface**: Built using PyQt5 with animated visual feedback.

## Programming Language:
- Python
## Framework:
